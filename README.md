# MODENA — Multipage Website

Static website ready for GitHub Pages. English-language, responsive, monochrome branding.

## Pages
- `index.html` — Home
- `platform.html` — Platform
- `architecture.html` — Architecture
- `about.html` — About

## Deploy to GitHub Pages
1. Extract the ZIP.
2. Upload the files and the `assets` folder to the **root** of your GitHub repository (not inside an extra `modena-site` folder).
3. In GitHub Settings → Pages, select **Deploy from a branch**, `main`, `/ (root)`.
4. Open the GitHub Pages URL once published.

## Assets
- `assets/logo.webp`: MODENA halftone bust logo
- Solid black page background (no background image)

The site contains informational pages, working internal navigation, mobile menu, and an X link to @UseModenaXyz. It does not pretend to provide live AI-agent backend functionality. Content describing the platform is editable in each HTML file.
